# Marca de agua KW

Herramienta para que los asesores agreguen logo y corredor interviniente (KW ON, KW Leloir o KW City) a las fotos de propiedades. Las fotos se procesan en el dispositivo del asesor; no se suben a ningún servidor.

Es una sola página (`index.html`). Cada cambio que se sube a `main` se publica solo.
